# SAP2000

Programa de CSI de **propósito general** por elementos finitos: puentes, naves industriales, tanques, torres, estructuras especiales, análisis no lineal avanzado (link, plasticidad, pushover, construcción por etapas).

## Formatos
`.SDB` (binario), `.$2K` / `.S2K` (texto).

## API — CSI OAPI
Misma arquitectura que [[ETABS]] (`SAP2000v1.dll`):
```python
import comtypes.client
helper = comtypes.client.CreateObject("SAP2000v1.Helper")
helper = helper.QueryInterface(comtypes.gen.SAP2000v1.cHelper)
sap = helper.GetObject("CSI.SAP2000.API.SapObject")
SapModel = sap.SapModel
```
Útil para generar modelos paramétricos (armaduras, pórticos, puentes) desde Python/Excel. MCP → [[MCP CSI - ETABS SAP2000 SAFE]].

## Cuándo usar SAP2000 vs ETABS
- Edificios con diafragmas y pisos → [[ETABS]].
- Geometría libre, puentes, estructuras especiales → SAP2000 (o CSiBridge para puentes).
