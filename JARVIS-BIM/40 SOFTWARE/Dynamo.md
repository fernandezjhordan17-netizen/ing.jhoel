# Dynamo

Plataforma de **programación visual** (nodos) de código abierto (DynamoDS), integrada en [[Revit]] y [[Civil 3D]] (y en otros productos). Archivos `.dyn` (JSON) y nodos personalizados `.dyf`.

## Capacidades
- Geometría computacional (ProtoGeometry), listas y datos, lectura/escritura de Excel/CSV/JSON.
- Acceso a la API de Revit/Civil 3D mediante nodos y **Python** (motor CPython 3 / PythonNet 3 en versiones recientes).
- **Dynamo Player** para ejecutar scripts sin abrir el editor; **Generative Design** para exploración de opciones.
- Paquetes comunitarios: Clockwork, Data-Shapes, Rhythm, archi-lab, Genius Loci, Springs, BimorphNodes, Civil3DToolkit, Camber (Civil 3D).

## IA en Dynamo
Con **Dynamo 4.2 en Revit 2027.3**, el *Autodesk Assistant* viene integrado junto a **DynamoMCP**, que permite al asistente leer y editar el grafo (colocar y conectar nodos, fijar entradas, ejecutar, leer advertencias, agrupar y guardar) → [[MCP Dynamo]].

## Aprendizaje
Dynamo Primer (DynamoDS/DynamoPrimerNew, licencia Apache 2.0) → [[Descarga de proyectos BIM]].

## Ejemplos útiles para JARVIS
- Numeración automática de elementos, creación de vistas/planos en lote, transferencia de parámetros desde Excel, metrados de acero, colocación de elementos por coordenadas.
