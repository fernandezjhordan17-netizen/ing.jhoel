# Speckle

Plataforma **open source** de datos AEC: conectores que envían/reciben **objetos** (no archivos) con control de versiones entre Revit, Rhino/Grasshopper, AutoCAD, Civil 3D, Tekla, ETABS, Navisworks, Archicad, Blender, Power BI, QGIS/ArcGIS, entre otros (según la generación de conectores).

## Por qué interesa a JARVIS
- **API GraphQL** y SDK Python (`specklepy`) → JARVIS puede consultar cualquier modelo enviado a Speckle sin abrir el software nativo.
- Historial de versiones por objeto (quién cambió qué).
- Dashboards (Power BI) de metrados/avance → [[KPIs de proyectos BIM]].
- Se puede alojar en servidor propio (cumplimiento de [[ISO 19650-5 - Seguridad de la informacion]]).
