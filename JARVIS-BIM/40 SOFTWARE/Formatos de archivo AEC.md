# Formatos de archivo AEC

| Extensión | Programa | Tipo | ¿Abierto? |
|---|---|---|---|
| `.rvt` `.rfa` `.rte` | [[Revit]] | Modelo / familia / plantilla | No |
| `.dyn` `.dyf` | [[Dynamo]] | Grafo / nodo (JSON) | Legible |
| `.dwg` `.dxf` `.dwt` | [[AutoCAD]], [[Civil 3D]] | Dibujo / intercambio / plantilla | DXF documentado |
| `.xml` (LandXML) | [[Civil 3D]] | Superficies, alineamientos | Sí |
| `.nwc` `.nwf` `.nwd` | [[Navisworks]] | Caché / federado / publicado | No |
| `.rtd` `.str` | [[Robot Structural Analysis]] | Modelo / texto | No / texto |
| `.edb` `.$et` `.e2k` | [[ETABS]] | Modelo / texto | Texto legible |
| `.sdb` `.$2k` `.s2k` | [[SAP2000]] | Modelo / texto | Texto legible |
| `.fdb` `.f2k` | [[SAFE]] | Modelo / texto | Texto legible |
| `.db1` (carpeta de modelo) | [[Tekla Structures]] | Modelo | No |
| `.xlsx` `.csv` | [[Excel]] | Datos | Sí |
| `.ifc` `.ifcxml` `.ifczip` | Todos | Modelo neutral | **Sí** → [[IFC - ISO 16739]] |
| `.ids` | Validadores | Requisitos | **Sí** → [[IDS - Information Delivery Specification]] |
| `.bcf` `.bcfzip` | Coordinación | Incidencias | **Sí** → [[BCF - BIM Collaboration Format]] |
| `.xlsx` (SAF) | Análisis estructural | Modelo analítico | **Sí** → [[SAF - Structural Analysis Format]] |
| `.e57` `.las` `.rcp` | Escáneres | Nube de puntos | E57/LAS sí → [[Scan to BIM]] |
| `.xer` / `.xml` (MSPDI) | Primavera P6 / MS Project | Cronograma | Documentados → [[Gestion del cronograma]] |
