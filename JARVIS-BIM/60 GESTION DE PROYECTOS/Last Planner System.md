# Last Planner System (Sistema del Último Planificador)

Desarrollado por Glenn Ballard y Greg Howell (Lean Construction Institute). Hace **confiable** la planificación involucrando a quienes ejecutan el trabajo.

## Niveles
1. **Plan maestro** (hitos) → [[Gestion del cronograma]]
2. **Planificación por fases** (pull planning colaborativo desde cada hito)
3. **Lookahead** (4–6 semanas): análisis de **restricciones** (diseño, materiales, mano de obra, equipos, permisos, espacio, información) y liberación
4. **Plan semanal** con compromisos confiables
5. **Aprendizaje**: **PPC** (Porcentaje de Plan Cumplido) = tareas completadas / tareas planificadas; análisis de **causas de no cumplimiento**

## BIM + LPS
- El modelo 4D hace visibles restricciones y secuencias ([[BIM 4D - Planificacion]]).
- Las restricciones "de información" (planos faltantes, RFIs) se vinculan a [[RFI y ordenes de cambio]].
- JARVIS calcula PPC y tendencias → [[KPIs de proyectos BIM]].
