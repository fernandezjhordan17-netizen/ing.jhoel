# Gestión del cronograma

## Proceso
EDT/WBS → lista de actividades → secuencia (FC, CC, FF, CF + adelantos/retrasos) → duraciones → **método de la ruta crítica (CPM)** → línea base → control.

## Conceptos
- **Holgura total/libre**, ruta crítica, hitos, calendarios, recursos, nivelación.
- Técnicas lineales para obras repetitivas: **línea de balance** y **takt planning** ([[Lean Construction]]).
- Compresión: *crashing* (más recursos) y *fast tracking* (solapar).

## Software y formatos
MS Project (`.mpp`, XML MSPDI), Primavera P6 (`.xer`, XML), Synchro, Asta; vínculo con modelos en [[Navisworks]] TimeLiner → [[BIM 4D - Planificacion]].

## Control
Avance físico vs programado, SPI ([[Gestion de costos y valor ganado]]), PPC ([[Last Planner System]]), curva S.
