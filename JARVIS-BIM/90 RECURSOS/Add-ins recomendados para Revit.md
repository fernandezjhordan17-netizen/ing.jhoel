# Add-ins recomendados para Revit (instalar desde el día 1)

| Add-in | Costo | Para qué |
|---|---|---|
| **Revit IFC** (exportador/importador open source de Autodesk) | Gratis | Exportar/importar IFC con más control (mapeo de clases, Psets, MVD) → [[IFC - ISO 16739]], [[MVD - Model View Definition]] |
| **pyRevit** | Gratis, open source | Decenas de herramientas extra + framework para tus propios scripts Python → [[Revit]] |
| **DiRoots ProSheets** | Freemium (150 exportaciones/mes) | Exportar planos en lote (PDF/DWG) |
| **Autodesk Model Checker** (BIM Interoperability Tools) | Gratis con Revit | **Auditar el modelo** contra reglas configurables → [[Control de calidad de modelos BIM]] |
| **Classification Manager** (BIM Interoperability Tools) | Gratis | Asignar **Uniclass u OmniClass** a los elementos → [[Sistemas de clasificacion]] |
| **IfcOpenShell / Bonsai** | Gratis, open source | Validar y editar IFC fuera de Revit → [[IfcOpenShell y Bonsai]] |

Las BIM Interoperability Tools de Autodesk incluyen además COBie Extension y el configurador de Model Checker → [[COBie]].

## Relación con JARVIS
- pyRevit y Model Checker son **complementos** de JARVIS: reglas deterministas que JARVIS puede ejecutar y cuyo resultado interpreta.
- Para automatización conversacional: [[MCP Revit]] y BIBIM ([[Herramientas de IA para BIM]]).
