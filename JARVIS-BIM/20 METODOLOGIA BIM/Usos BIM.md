# Usos BIM

Un **uso BIM** es un método de aplicar BIM durante el ciclo de vida para lograr un objetivo específico. Referencia clásica: *BIM Project Execution Planning Guide* (Penn State CIC; la **v3** incluye plantillas Excel/PDF → [[Fuentes y referencias]]) — 25 usos:

| Fase | Usos |
|---|---|
| Planificación | Modelado de condiciones existentes ([[Scan to BIM]]), estimación de costos ([[BIM 5D - Costos y metrados]]), planificación por fases ([[BIM 4D - Planificacion]]), programación, análisis de sitio |
| Diseño | Revisión de diseño, **autoría de diseño**, análisis estructural, de iluminación, energético ([[BIM 6D - Sostenibilidad]]), mecánico, otros análisis de ingeniería, evaluación de sostenibilidad, validación de normativa |
| Construcción | **Coordinación 3D** ([[Coordinacion BIM y deteccion de interferencias]]), planificación de uso del sitio, diseño de sistemas constructivos, fabricación digital, control y replanteo 3D, modelado de registro (as-built) |
| Operación | Programación de mantenimiento, análisis de sistemas, gestión de activos, gestión de espacios, planificación de desastres ([[BIM 7D - Operacion y mantenimiento]]) |

## Cómo usarlos
1. El cliente elige los usos en el [[EIR - Requisitos de Intercambio de Informacion]] según objetivos.
2. Cada uso define la información requerida ([[LOIN - Nivel de Informacion Necesaria]]).
3. El [[BEP - Plan de Ejecucion BIM]] describe cómo se ejecutará cada uso (procesos, software, responsables).

## Usos BIM que JARVIS automatiza primero
Análisis estructural ([[ETABS]]), coordinación 3D ([[Navisworks]]), metrados ([[Excel]]), validación de normativa (IDS + reglas E.030).
