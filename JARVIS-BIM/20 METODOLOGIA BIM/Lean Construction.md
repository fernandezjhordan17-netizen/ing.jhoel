# Lean Construction

Filosofía de producción que maximiza valor y minimiza desperdicios (Koskela, 1992; Lean Construction Institute).

## Principios
- Valor definido por el cliente, flujo continuo, sistema "pull", mejora continua (kaizen), respeto por las personas.
- **8 desperdicios** (TIMWOODS): transporte, inventario, movimiento, espera, sobreproducción, sobreprocesamiento, defectos, talento no usado.

## Herramientas
- [[Last Planner System]] (planificación colaborativa y PPC)
- Takt planning, 5S, A3, Value Stream Mapping, Target Value Design
- Integración con [[BIM 4D - Planificacion]]: el modelo hace visible el flujo y los lotes de trabajo.

## Sinergia BIM + Lean
BIM elimina desperdicios de información (RFIs, reprocesos) → [[RFI y ordenes de cambio]]; Lean organiza el flujo de trabajo en obra → [[VDC - Diseno y Construccion Virtual]].
