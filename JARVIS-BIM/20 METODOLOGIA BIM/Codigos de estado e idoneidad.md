# Códigos de estado (idoneidad) y revisión

Tabla del Anexo Nacional UK de ISO 19650-2 (referencia muy extendida):

| Estado CDE | Código | Significado |
|---|---|---|
| WIP | **S0** | Trabajo en curso |
| Compartido | **S1** | Apto para coordinación |
| Compartido | **S2** | Apto para información |
| Compartido | **S3** | Apto para revisión y comentarios |
| Compartido | **S4** | Apto para aprobación de etapa |
| Compartido | **S6** | Apto para autorización del PIM |
| Compartido | **S7** | Apto para autorización del AIM |
| Publicado | **A1, A2…** | Autorizado y aceptado (etapa n) |
| Publicado | **B1, B2…** | Parcialmente autorizado, con comentarios |
| Publicado | **CR** | Registro de obra (as-built) |

## Revisiones
- **P01, P02…** preliminar (no contractual); sub-versiones **P01.1, P01.2** durante WIP.
- **C01, C02…** contractual (publicado).
