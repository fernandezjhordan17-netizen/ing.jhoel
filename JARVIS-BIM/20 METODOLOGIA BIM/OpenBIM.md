# OpenBIM

Enfoque colaborativo basado en **estándares abiertos y neutrales** (buildingSMART) en lugar de depender de un único fabricante ("closedBIM"/"littleBIM").

## Estándares del ecosistema openBIM
| Qué intercambia | Estándar |
|---|---|
| Modelo (geometría + datos) | [[IFC - ISO 16739]] |
| Requisitos verificables | [[IDS - Information Delivery Specification]] |
| Incidencias/comentarios | [[BCF - BIM Collaboration Format]] |
| Diccionarios de propiedades | [[bSDD - buildingSMART Data Dictionary]] |
| Procesos de intercambio | [[ISO 29481 - IDM]] · [[MVD - Model View Definition]] |
| Datos de FM | [[COBie]] |

## Principios buildingSMART (resumen)
Interoperabilidad, estándares abiertos, flujos confiables, trazabilidad, independencia del proveedor, flexibilidad, sostenibilidad de los datos a largo plazo.

## ¿Nativo o IFC?
- **Nativo** (RVT, DB1, EDB) para producción dentro del equipo.
- **IFC** para intercambio contractual, archivo a largo plazo y revisión por terceros. La [[Guia Nacional BIM Peru]] promueve formatos abiertos para entregables públicos.
