# Historia del BIM

| Año | Hito |
|---|---|
| 1962–1975 | Sketchpad (Sutherland); Charles Eastman describe el "Building Description System" (1975) |
| 1984 | ArchiCAD (Graphisoft) – primer "edificio virtual" comercial |
| 1994 | Nace la IAI (International Alliance for Interoperability), hoy **buildingSMART** |
| 1997 | Primera versión de **IFC** (IFC 1.0) → [[IFC - ISO 16739]] |
| 2000–2002 | Revit Technology Corp.; Autodesk compra Revit (2002) y populariza el término "BIM" |
| 2005 | IFC2x2/IFC2x3 → ISO/PAS 16739:2005 |
| 2007 | BS 1192:2007 (colaboración y nomenclatura) → [[PAS 1192 - Antecedente britanico]] |
| 2011–2016 | Estrategia BIM del gobierno del Reino Unido: "BIM Nivel 2" obligatorio en 2016 → [[Niveles de madurez BIM]] |
| 2013 | IFC4 (ISO 16739:2013) |
| 2018 | **ISO 19650-1 y -2** → [[ISO 19650 - Serie completa]] |
| 2019 | Perú: DS 289-2019-EF crea el marco de adopción BIM → [[Plan BIM Peru]] |
| 2020–2022 | ISO 19650-3, -5 (2020), -4 (2022) |
| 2024 | **IFC 4.3 = ISO 16739-1:2024** (infraestructura); **IDS 1.0** aprobado; ISO 7817-1 (LOIN) |
| 2025 | ISO 19650-6 (salud y seguridad); Perú: RD 0007-2025-EF/63.01 fija tipologías obligatorias |
| 2026 | IA agéntica + MCP en software AEC (Revit 2027 MCP, DynamoMCP) → [[MCP - Fundamentos]]; obligatoriedad BIM en Perú desde 14-08-2026 |

## Lección
El BIM evolucionó de **geometría** → **objetos con datos** → **procesos colaborativos** → **información conectada e IA**. JARVIS se ubica en la última etapa ([[JARVIS - Vision y alcance]]).
