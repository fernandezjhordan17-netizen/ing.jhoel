# Roles BIM

## Partes según ISO 19650 (roles contractuales)
| Parte | Descripción |
|---|---|
| **Parte que designa** (appointing party) | Cliente/propietario que recibe la información |
| **Parte designada principal** (lead appointed party) | Coordina a un equipo de entrega (p. ej. contratista general, proyectista líder) |
| **Parte designada** (appointed party) | Proveedor de información (especialistas, subcontratistas) |
| **Equipo de entrega / equipo de tarea** | Agrupaciones de personas que producen información |

ISO 19650 habla de **funciones** de gestión de la información, no de cargos fijos → [[Matriz de responsabilidades]].

## Cargos de mercado
| Cargo | Responsabilidades principales |
|---|---|
| **BIM Manager / Gestor BIM** | Estrategia, EIR/BEP, estándares, CDE, auditorías, KPIs |
| **Coordinador BIM** | Federación, detección de interferencias, reuniones de coordinación, BCF |
| **Modelador / Especialista BIM** | Producción de modelos por disciplina |
| **Supervisor BIM** (Perú, sector público) | Verifica cumplimiento del EIR/BEP por parte del contratista |
| **Especialista en automatización / BIM Developer** | Dynamo, APIs, scripts, MCP (tu rol con JARVIS) |

## Perú
La [[Guia Nacional BIM Peru]] describe roles para la entidad pública y para los proveedores; revisar la versión vigente.

## JARVIS como "miembro del equipo"
JARVIS asume tareas repetitivas de coordinador y modelador, pero **no reemplaza** la responsabilidad profesional (firma, criterio) → [[JARVIS - Seguridad y gobernanza]].
