# ISO 29481 — Information Delivery Manual (IDM)

Metodología para **documentar procesos de intercambio de información**: quién entrega qué información, a quién, cuándo y para qué.

| Parte | Tema |
|---|---|
| ISO 29481-1:2016 | Metodología y formato |
| ISO 29481-2:2012 | Marco de interacción |
| ISO 29481-3:2022 | Esquema de datos (idmXSD) |

## Componentes de un IDM
1. **Mapa de procesos** (BPMN) con actores y eventos.
2. **Requisitos de intercambio** (Exchange Requirements, ER): la información de cada intercambio.
3. Implementación técnica: [[MVD - Model View Definition]] / [[IDS - Information Delivery Specification]].

## Ejemplo aplicado
IDM "Modelo arquitectónico → análisis estructural": ER = ejes, niveles, muros portantes, losas, columnas, vigas con material y sección → implementado como IDS + mapeo a [[ETABS]] ([[Interoperabilidad entre software]]).
