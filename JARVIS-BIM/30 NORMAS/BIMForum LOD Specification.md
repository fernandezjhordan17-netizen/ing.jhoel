# BIMForum LOD Specification

Documento de referencia (EE.UU., BIMForum, publicado periódicamente) que define para cada elemento —organizado por **UniFormat**— qué significa LOD 100/200/300/350/400, con **ilustraciones** y atributos.

## Cómo usarla
1. Tabla de elementos (UniFormat) × hitos del proyecto → LOD requerido.
2. Adjuntarla al [[BEP - Plan de Ejecucion BIM]] o al [[EIR - Requisitos de Intercambio de Informacion]].
3. Verificar con [[Control de calidad de modelos BIM]].
