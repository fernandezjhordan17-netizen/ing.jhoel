# bSDD — buildingSMART Data Dictionary

Servicio en línea (search.bsdd.buildingsmart.org + API REST/GraphQL) que publica **diccionarios** de clases y propiedades: IFC, Uniclass, ETIM, CoClass, NL-SfB, diccionarios nacionales y de fabricantes.

## Usos
- Enriquecer objetos con propiedades estandarizadas (plugins bSDD para Revit, Archicad, Bonsai).
- Referenciar requisitos en [[IDS - Information Delivery Specification]] (propiedades con URI del bSDD).
- Mapear clasificaciones nacionales ↔ IFC ([[Sistemas de clasificacion]]).

## Normas base
[[ISO 12006 - Clasificacion]] (12006-3) · [[ISO 23386 y 23387 - Plantillas de datos]]

## JARVIS
Consulta la API del bSDD para proponer propiedades y códigos cuando redacta un EIR o un IDS.
